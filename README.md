# Spectre Studio

**Your AI-powered desktop workspace for meetings, interviews, productivity, and device mirroring.**

Spectre Studio is a powerful desktop application designed to make your everyday work easier. It brings AI assistance, meeting transcription, interview support, screen recording, and Android device mirroring into one application.

This repository is the official public download page for Spectre Studio.

**Windows installation:**
1. Open the [Latest Releases](../../releases/latest) page.
2. Download `SpectreStudio-x.x.x-Setup.exe`.
3. Run the downloaded installer.
4. Follow the installation instructions.
5. Launch Spectre Studio.

> **Windows Security Notice:** Windows SmartScreen may display a security warning because the application is currently not code-signed. Only download releases from this official repository.

## ✨ Features

- **AI Assistant:** Connect with Google Gemini, OpenAI, OpenRouter, Anthropic Claude, Ollama, and other compatible AI providers.
- **Meeting Transcription:** Record meetings and convert speech into searchable text.
- **Interview Copilot:** AI-powered interview assistance, question detection, and coding problem analysis.
- **Screen Recording:** Record your screen, webcam, and microphone.
- **Screenshot & OCR:** Capture, annotate, and extract text from screenshots.
- **Stealth Mode:** Use a translucent always-on-top desktop overlay with supported screen-sharing protection.
- **Android Device Casting:** Mirror Android devices to your desktop through wireless connections.
- **Multiple Export Formats:** Export transcripts and meeting notes in TXT, JSON, SRT, and Markdown formats.

## 🔐 Privacy & Security

- No traditional account registration is required.
- The application uses your operating-system account.
- AI API keys are encrypted using the operating-system secure storage where supported.
- Your provider credentials are configured locally.
- Local Whisper is available for offline transcription.

Please review the application's privacy and security considerations before using it with sensitive information.
